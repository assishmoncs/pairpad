# Code of Conduct

PairPad contributors are expected to keep project discussions and contributions respectful, technical, and inclusive.

## Expected behavior

- Be respectful and constructive.
- Focus feedback on code, design, evidence, and user impact.
- Assume good intent while challenging technical decisions directly.
- Protect credentials, private data, and security-sensitive information.

## Unacceptable behavior

- Harassment, discrimination, threats, or personal attacks.
- Publishing private information without permission.
- Deliberately introducing malicious code or secrets.
- Disrupting project infrastructure or abusing services.

Project maintainers may remove comments, reject contributions, or restrict participation when these standards are violated.

For security vulnerabilities, do not use public issues; follow `SECURITY.md`.
